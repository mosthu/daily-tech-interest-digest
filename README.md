# NVIDIA & AMD 消费级显卡中国大陆价格日报

每天北京时间 09:00 查询京东、淘宝、拼多多和抖音的 NVIDIA GeForce 与 AMD Radeon 全新消费级桌面显卡，并单独查询闲鱼、转转等二手平台；同时抓取最近 48 小时的硬件新闻，记录价格历史，并通过 PushPlus 推送到微信。

监控范围按 GPU 芯片型号覆盖 NVIDIA RTX 50/40/30/16 系列和 AMD Radeon RX 9000/7000/6000 系列。每个平台、每个型号只保留当前抓到的最低报价，避免同一芯片的几十个品牌 SKU 刷屏。

## 使用方式

1. 将本目录上传到自己的 GitHub 仓库。
2. 在 PushPlus 获取个人 Token，并在 GitHub 仓库中进入 **Settings → Secrets and variables → Actions**，新建 Secret：
   - Name：`PUSHPLUS_TOKEN`
   - Secret：你的 PushPlus Token
3. 在仓库的 **Actions** 页面手动运行一次 `NVIDIA & AMD consumer GPU daily price report`，确认能收到测试消息。
4. 之后由 GitHub Actions 每天自动运行。定时任务使用 `01:00 UTC`，对应北京时间 `09:00`；GitHub 的计划任务可能有少量延迟。

## 日报内容

- 每个 GPU 芯片型号的当前最低价、商品名称、京东店铺和商品链接
- NVIDIA 与 AMD 品牌分类
- 标准/主流非公版或特殊/高端非公版分类
- 全新卡的平台对比：京东、淘宝、拼多多、抖音
- 二手卡的平台对比：闲鱼、转转
- 各平台近 30 天低价
- 最近的显卡、内存、CPU、SSD 等硬件新闻及原文链接
- 基于供需、库存、涨价、降价、促销和新品节奏的后续价格趋势判断
- 首次运行后，历史价格会逐日积累；低价数据不会凭空补齐

## 注意事项

- 淘宝、拼多多、抖音、闲鱼和转转经常需要登录、动态渲染或触发验证；日报会把抓不到的平台显示为“—”，不会用搜索摘要冒充真实报价。
- 所谓“在售”以当天能抓到的公开报价为准；各平台显示的可能是券后价、补贴价、拼单价或搜索页最低价，不能直接视为同一商品的最终成交价。
- 旧型号可能只有散片、库存尾货或二手/翻新商品，脚本无法始终准确判断商品成色；购买前请打开链接确认“全新”和售后信息。
- 二手平台价格是挂牌价，不是最终成交价；需要自行核对成色、维修史、矿卡风险、序列号、发票和售后。
- 新闻来自公开 RSS；如果新闻源暂时不可用，日报仍会照常推送价格部分。
- 趋势判断是基于新闻标题和摘要的自动研判，不是保证涨跌的投资或购买结论。
- 京东券、跨店满减、以旧换新和会员价可能没有包含在页面标价中。
- PushPlus 的 Token 只放在 GitHub Secret 中，不要写进代码或提交到仓库。
